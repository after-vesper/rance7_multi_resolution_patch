戦国ランス マルチ解像度パッチ (Phase 1)
========================================

概要
----
ゲームの描画内容(800x600)を任意の解像度にスケーリングして表示する
パッチです。ウィンドウサイズの切替・手動リサイズ・ボーダーレス全画面
を追加し、マウス座標・カーソル位置も正しく変換されます。

収録ファイル
------------
  dinput.dll    プロキシ DLL (ゲーム本体を改変しません)
  MultiRes.ini  設定ファイル
  README.txt    このファイル

インストール
------------
1. ゲームのインストールフォルダ (Rance7.exe がある場所) に
   dinput.dll と MultiRes.ini をコピーするだけです。
2. ゲームを起動すると自動的に有効になります。

   既に dinput.dll が存在する場合は他の MOD/パッチと競合する
   可能性があるため、事前にバックアップを取ってください。

アンインストール
----------------
dinput.dll と MultiRes.ini を削除してください。
ゲーム本体・セーブデータは変更されません。

使い方
------
■ 解像度の変更
  メニューの [設定] → [解像度...] を開き、ドロップダウンから
  選択して OK。即座に反映され、次回起動時も保持されます。
  選択肢はすべて 4:3 (元の画面比率) です。

■ 手動リサイズ
  ウィンドウの枠をドラッグして自由にサイズ変更できます。
  サイズは終了時に保存されます。4:3 以外のサイズでは
  黒帯(レターボックス)が表示されます。

■ ボーダーレス全画面
  システムメニューの「ﾎﾞｰﾀﾞｰﾚｽﾌﾙｽｸﾘｰﾝ」または Alt+B で
  切替。解除も Alt+B です。マルチモニタではウィンドウがある
  モニタ全体を覆います。

■ 通常のフルスクリーン
  メニューの「ﾌﾙｽｸﾘｰﾝ」/ Alt+Enter / 最大化ボタンは従来通り
  ゲーム内蔵のフルスクリーン(800x600モード切替)です。
  ボーダーレスとは排他で、どちらか一方のみ有効になります。

設定ファイル (MultiRes.ini)
---------------------------
[Display]
  Width / Height  出力解像度 (初期値 800x600 = オリジナル)
  Filter          0=ドット感維持(ニアレスト) / 1=なめらか
  ScaleMode       0=引き伸ばし / 1=4:3維持(黒帯) / 2=整数倍
  Fullscreen      1=起動時にボーダーレス全画面で開始
[Debug]
  Log             1=multires_log.txt に診断ログを出力

注意事項
--------
- スナップショット機能で保存される画像は内部バッファそのままの
  800x600 です (仕様)。
- モニタの表示解像度を超えるサイズを選んだ場合、ウィンドウが
  画面からはみ出します。タイトルバーは画面上に残るので掴んで
  移動できます。
- アンチウイルスソフトが DLL を誤検知する場合があります。
  その場合は除外設定を行ってください。

対象: 戦国ランス / Sengoku Rance (System40)
