# 戦国ランス マルチ解像度パッチ 実装仕様

## 1. 対象環境

- ゲーム: Sengoku Rance (戦国ランス) Kagura Games 版
- エンジン: Alicesoft System 4.0 (Ver.1.31), VM = Sys42VM
- 内部描画解像度: 800×600 固定 (SACT 座標系)
- 画面出力: Direct3D9 (`DLL/D3D9Factory.dll` が `CreateInterface` で生成)
- 起動設定: `System40.ini` の `ViewWidth` / `ViewHeight`

## 2. 実機検証結果 (2026-10-04)

`System40.ini` を `1600×1200` に変更して起動した結果:

- ウィンドウのクライアント領域は 1600×1200 で作成される (ini は有効)
- ゲーム内容は左上 800×600 のみに描画され、残りは黒
- つまり ini の View サイズはバックバッファ/ウィンドウサイズのみに影響し、
  コンテンツの描画スケールには影響しない

## 3. 描画パイプライン (逆アセンブル調査結果)

`Rance7.exe` 内に Direct3D9 デバイスを直接操作するコードがある:

- フレーム描画: `0x41c854` 付近
  - `IDirect3DDevice9::Clear` (vtable 0xac)
  - `BeginScene` (0xa4)
  - 内部関数 `0x41de90` — メインサーフェース(テクスチャ)をクアッド描画
  - `EndScene` (0xa8)
  - `Present` (0x44)
  - 同様のシーケンスが複数箇所に存在 (0x41ca32, 0x41cad8, 0x41cbf3 等:
    ウィンドウ/フルスクリーン/メニュー等の経路別)
- 初期化: `0x41be70` — スワップチェーン/テクスチャ/深度バッファ生成と
  **宛先矩形の計算** (0x41c091-0x41c0cb)
  - `(ビュー幅 - コンテンツ幅)/2` 形式でセンタリングオフセットを算出
  - 結果をオブジェクトフィールドに格納:
    - +0x68, +0x6c: オフセット (x, y)
    - +0x70, +0x74: サイズ (w, h)
    - +0x78: z = 0.0, +0x7c: rhw = 1.0f → RHW 変換済み頂点クアッド

## 4. Phase 1 実装方針: 出力解像度切替

### 方針

内部描画は 800×600 のまま維持し、最終クアッドの宛先矩形を出力解像度に
合わせて拡大する。GPU によるバイリニア/ポイントスケーリング。

### 実装方式の選択肢

- **A. exe バイナリパッチ**: `0x41c0b2` 付近の矩形格納処理を書き換え、
  宛先矩形 = ビュー全体とする。解像度切替は ini 書き換え or 独自 ini キー
  追加+exe のパース処理パッチ
- **B. d3d9.dll プロキシ (推奨)**: ゲームフォルダに d3d9.dll を置き、
  `Direct3DCreate9` をラップ。`CreateDevice`/`Reset` でバックバッファサイズ
  とウィンドウサイズを制御し、`Present` 前にクアッド描画を差し替え、または
  `StretchRect` 互換の拡大 blit を挟む。exe 無改造で済み、
  フィルタリング設定(ニアレスト/バイリニア/xBR 系シェーダ)も
  プロキシ側で自由に実装可能
- **C. DrawPlugin 差替**: `DrawPluginDLL.inc` に追加する方式は
  プラグインがスプライト単位の描画用であり最終 Present には届かないため
  今回の用途には不向き (要追加調査)

### 解像度プリセット案 (4:3)

800×600 / 1024×768 / 1280×960 / 1600×1200 / 1920×1440 / 2560×1920
(整数倍 1600×1200, 2400×1800 を優先。非整数倍はフィルタリング必須)

### 設定 UI

- `System40.ini` に独自キーを追加するか、パッチ同梱の設定ツール
  (ランチャー exe) で ini を書き換える方式
- 起動時フルスクリーン選択メニュー (`Sys40FullScreenMenuClass`) は
  エンジン標準機能のため温存

## 5. Phase 2: アセット高解像度化

- `Rance7*.ald` の展開 → CG を AI アップスケール (x2) → 再パック or
  優先度の高い差分 `.ald` を追加
- 要調査: `ALDLoader.dll` のアーカイブ解決順序 (同名ファイルの優先度)
- `.fnl` フォントの高解像度版も必要になる可能性

## 6. Phase 3: HD アセットモード切替

- HD モードでは実解像度描画が必要:
  - View を実解像度に設定した上で、SACT のスプライト座標・
    `ISurface` サイズをスケール倍率で変換するレイヤを挟む
    (`SACT2.dll` の `IDrawPluginDrawer` フック)
  - フォント (`SengokuRanceFont.dll` / `DrawText2.dll`) の
    サイズ変換も別途対応
- SD/HD 切替は ini 設定 + 起動時切替で実現

## 7. 配布形式

公式パッチ (`Sengoku Rance JP Patch v1.exe`) は Indigo Rose Setup Factory
製インストーラーでファイルを丸ごと差し替える形式。
本パッチは以下のいずれかで配布:

- Setup Factory 等のインストーラー (公式に倣う)
- シンプルな zip 展開 + 設定ツール
